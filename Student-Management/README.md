# Salesforce Application Setup
Click on settings icon
Click on setup
Click on Objects and Fields -> Object Manager
Click on Create -> Custom Object
Enter Label = Student, Plural Label = Students, Object Name = Employee, Record Name = Employee Name, Datatype = text 
Click Save 
Go to Fields & Relationships
Click on new and add the fields that we want by selecting the datatype and entering the Label.
Add the numbmer of required fields
Now we need to create Apex Class
Again go to setup and search apex classes 
Click on new and paste the StudentController.cls code in the editor that appears and click save
Now we need to create Visualforce Page
Again go to setup and search visualforce pages 
Click on new, add label as StudentManagement and paste the StudentManagement.page code in the editor that appears and click save
Clcik on preview to view our application and test it
